# Provider Storage

Declare S3 buckets, access grants, credential rotation, and lifecycle rules
in a namespaced `Storage` resource. Provider Storage supports MinIO, AWS,
Open Telekom Cloud (OTC), OVHcloud, and CloudFerro.

Platform operators start with [Installation](how-to-guides/installation.md)
and [Cloud IAM bootstrap](how-to-guides/cloud-iam-bootstrap.md).
For bucket creation and consumer credentials, see
[Use Storage](how-to-guides/usage_concepts.md).
[Permissions](how-to-guides/permissions.md) explains sharing, and
[Backend differences](how-to-guides/backend_differences.md) describes access
rules and limits. The [API reference](reference-guides/api.md) lists resource
fields.

For repository development, see [Local tests](how-to-guides/local_setup.md).
